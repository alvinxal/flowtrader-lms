## Server yang Termasuk

- Satu server production untuk aplikasi dan database.
- Konfigurasi domain dan SSL.
- Monitoring uptime, error, dan penggunaan resource.
- Backup otomatis sesuai paket managed service.
- Penyimpanan aplikasi dan database maksimal 20 GB.
- Maksimal 1.000 akun member terdaftar.
- Maksimal 100 pengguna aktif secara bersamaan.
- Bandwidth aplikasi maksimal 200 GB per bulan.
- Upgrade server akan dibicarakan dan ditagihkan terpisah apabila penggunaan melampaui batas paket.

## Permintaan Ringan yang Termasuk

- Mengubah harga atau deskripsi paket.
- Mengganti link komunitas.
- Mengubah teks atau gambar.
- Mengatur popup promo dan notifikasi.
- Membantu masalah akses member.
- Penyesuaian kecil pada tampilan.
- Mengunggah atau mengganti materi sesuai kuota paket.

## Tidak Termasuk Managed Service

- Pembuatan fitur atau modul baru.
- Perombakan desain atau alur aplikasi.
- Integrasi layanan pihak ketiga baru.
- Migrasi data dalam jumlah besar.
- Aplikasi Android atau iOS.
- Sinkronisasi role Discord otomatis.
- Biaya domain, payment gateway, email transaksional, serta penyimpanan dan bandwidth video/CDN.
- Pekerjaan di luar kuota; dikenakan biaya tambahan **Rp150.000 per jam** setelah mendapat persetujuan.
