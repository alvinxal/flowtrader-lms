# Daftar Fitur: Platform Kelas Flow Trader

Dijual per paket, bukan per kelas. Hanya ada 2 paket: Basic dan Mastery.

## Fitur MVP (Minimum Viable Product)

### 1. Penjualan dan pembayaran
- Halaman paket dan detailnya
- Checkout Payment Gateway
- Paket sekali bayar
- Akses paket setelah bayar
- Email konfirmasi pembayaran + link akses platform

### 2. Membership
- Daftar dan masuk platform (manual atau Google)
- Form pendaftaran: manual (nama, email, password, no HP, akun Discord) atau Google (nama, no HP, akun Discord)
- Welcome screen setelah membeli paket
- Pembatasan akses member panel (hanya pemilik paket Basic/Mastery)
- Paket saya dan riwayat pembelian
- Modul terkunci (blur/lock) untuk paket Basic
- Upgrade: paket Basic → paket Mastery
- Halaman utama pembelajaran
- Sertifikat
- Video terakhir diakses

### 3. Digital Rights Management (DRM) Video
- Streaming Management
- Temporary URL Video
- Watermark secara dinamis

### 4. Panel admin
- Kelola paket, kelas, video, dan harga
- Daftar member dan pembelian
- Beri/cabut akses
- Kelola template sertifikat
- Ekspor CSV/Excel
- Popup promo
- Ringkasan penjualan

### 5. Komunitas dan notifikasi
- Link join Discord/Slack/Telegram
- Kelola link komunitas (Discord/Slack/Telegram)
- Notifikasi Platform
- Kelola notifikasi platform (admin)
